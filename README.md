# 再逛一次

面向城市再访者的行程规划 chatbot，目前支持香港、上海和柏林。通过建筑师、当地居民、厨师等角色视角，帮助用户发现新的玩法，并在对话中形成可调整的路线。

## 核心流程

1. 自然语言描述需求，核对目的地、人数、预算和天数；可补充偏好片区、不去哪里、出发地和日期。
2. 根据兴趣、片区、体力和排除项召回、排序本地地点素材，以「角色 × 地点 × 行动类型」生成最多 3 个方向。候选不足时如实说明。
3. 选择方向后生成每日行程，保留对应地点和核心行动，支持锁定某天、调整预算、强度和费用。

「不去哪里」可在确认表单中编辑；与偏好片区冲突时以排除项为准。地图查询失败时保留已有地点或行程，并提供重试。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
cp .env.example .env
```

在 `.env` 中填写 `DEEPSEEK_API_KEY`，模型由 `DEEPSEEK_MODEL` 指定，当前默认 `deepseek-v4-flash`。

```bash
npm run dev
```

打开 <http://127.0.0.1:5173>。如需代理，设置 `TRAVEL_PLANNER_PROXY`；后端不会自动使用系统代理。

## 当前边界

地点候选来自本地素材库，尚未接入实时全网检索。价格和营业信息需另行确认，预算不含往返机票或火车；地图依赖外部服务，用于路线预览。会话保存在服务端内存和当前浏览器标签页，没有账号或跨设备同步。
